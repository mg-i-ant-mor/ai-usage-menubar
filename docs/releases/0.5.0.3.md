# AI Usage 0.5.0.3

- Pace-aware risk: each limit window gets a confidence-weighted pace zone, and
  the bar's on-pace tick, the panel hourglass and the menu bar mark risk by that
  zone. Usage-level colours are muted while the pace is calm, and the panel says
  when a window is back on pace.
- The forecast no longer waits for 10% usage and survives stale readings.
- Claude's own high-usage flag is shown as information, not as a warning.

This build is signed ad-hoc and not notarized. The first time you open the
downloaded DMG, right-click the app and choose Open.
