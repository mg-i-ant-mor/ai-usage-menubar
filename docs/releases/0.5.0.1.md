# AI Usage 0.5.0.1

First release of the mg-i-ant-mor fork, built on AI Usage 0.5.0. From this
version on, updates come from this fork's feed, signed with the fork's own
Sparkle key.

- Forecast when a limit runs out, using your working hours.
- Track more than one Claude account, each identified by its keychain login.
- Show a detailed tooltip, with limit icons colored by how much is used.
- Show a daily budget until each long limit resets, and mark the on-pace point
  on each limit's bar.

This build is signed ad-hoc and not notarized. The first time you open the
downloaded DMG, right-click the app and choose Open.
